# Cityflo ops MCP server

Server: `server.py` (tools) over `store.py` (datasets by ISO week) and `analytics.py` (lateness). Run with `.venv/bin/python server.py`.
Task brief and Priya's handoff are in `instructions/`; sample data is in `demo/`; managed datasets are in `data/` (do not edit by hand).
